## Summary

Sixth open-beta cut on package tree **2.0.0**. Fixes Discovery Add Friend vanity resolve on the production desktop pool. Dual-channel Share (QR / OB2) remains the preferred Add Friend path; vanity is secondary but must work when aliases exist on public discovery relays.

Honesty bounds unchanged: **1:1 voice shipped · video not usable · Tor unverified · Soft L3 PAUSED · Matrix / Private DC lab only**.

## What's new since beta.5

- **Friend-code discovery (conduit)** — invite/community lookup sends Nostr `REQ` via `sendToOpen`; no longer routes through mesh publish envelope.
- **Transient discovery dials** — `addTransientRelay` opens global discovery relays for invite lookup.
- **Regression proof** — L1 invite REQ contract test; investigation dated 2026-11-05.
