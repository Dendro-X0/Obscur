## Follow-up proofs (2026-08-24) — WebView cold start + SQL indexes

These were listed as audit gaps; measured locally against the release exe + live Roaming DB.

### WebView cold start (release exe + CDP)

**Artifact:** [`docs/assets/perf/v2-webview-cold-start-2026-08-24.json`](../assets/perf/v2-webview-cold-start-2026-08-24.json)

| Metric | Value | Notes |
|--------|-------|-------|
| Process spawn → CDP listen | **1215 ms** | `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9230` |
| WebView DCL | **184 ms** | Navigation Timing |
| First Contentful Paint | **216 ms** | Navigation Timing paint |
| Load event | **407 ms** | Navigation Timing |
| Spawn → unlocked Chats shell | **Not this run** | Cold land on `/profiles` picker (timeout ~120s) |

**Read:** Native + WebView2 bring-up is ~1.2s before CDP; document paint inside the WebView is sub-500ms. Unlock-to-messenger is **keychain/profile-picker dependent** — not proven as a single spawn→Chats number on this cold kill.

**Still does not prove:** multi-machine variance · OS reboot · F5-only · empty first install.

### SQL index coverage (live `obscur.sqlite3`)

**Artifact:** [`docs/assets/perf/v2-sqlite-index-coverage-2026-08-24.json`](../assets/perf/v2-sqlite-index-coverage-2026-08-24.json)
