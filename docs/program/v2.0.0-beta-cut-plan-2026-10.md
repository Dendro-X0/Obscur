## 1. Verdict

**Obscur is past the useful engineering shelf for beta.** Crypto defaults, voice, dual-tier communities (CU-UX-2b→6 L1), relays honesty, and Gift demo paths already exist. The trap is treating every L3 skip, video gap, and Spaces idea as a beta blocker.

**Beta = honest desktop evaluator build + tagged notes + known limitations.** Not a perfect product.
