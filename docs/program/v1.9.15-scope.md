## Theme

Make **ciphertext path choice** honest and latency-aware across Obscur’s real channels — public Nostr, operator/VPS relays, custom pools, LAN/lab, VPN/proxy, and Tor — and prove **two-profile DM delivery** (Soft L3) before tagging **v1.9.15**. Plan (do not fully ship) Starlink-class / DTN / NIP-65 as **future dialects**, not parallel transport owners.

**One sentence for users:** “Obscur picks the shortest honest path for your encrypted messages — and tells you when privacy or satellite links will feel slow.”

---

## Product bar

| Must be true | Explicitly not required |
|--------------|-------------------------|
| Soft L3 Pass on agreed path (lab local **or** shared remote) | Public Nostr SLA / every relay always online |
| Dial set does not starve enabled remotes behind live local primary | Identical Relays lists on every peer |
| Publish prefers publish-ready remotes by observed RTT when peers are remote | Tor/VPN as fast as clearnet |
| Path class visible (LAN / clearnet / Tor / offline) | Perfect anonymity / traffic analysis resistance |
| Design + roadmap for satellite / DTN / outbox | Full NIP-65 or Starlink L3 in this tag |

## Honesty language (public)

- “Networks carry **ciphertext**; path length (LAN vs clearnet vs Tor vs satellite) changes how fast chat feels.”
- Soft L3 Pass = **delivery on an agreed path**, not a global Nostr uptime guarantee.
- Tor and stacked VPN/proxy are **privacy choices** that trade latency.
- Offline / DTN is **store-and-forward**, never fake live relay delivery.
