# Contributing (feedback-first)

Obscur is a **public, source-available** project. Review and feedback are welcome. **Code changes are made only by the maintainer** while the project is early.

## Welcome

- Security findings, bug reports, and clear reproduction notes
- UX / docs suggestions and design critique
- Questions that help tighten claims vs. behavior
- Short, attributed excerpts in research or news (see [`LICENSE`](./LICENSE))

Prefer **Issues** (or Discussions, if enabled) over pull requests.

## Not expected right now

- Unsolicited feature PRs or large refactors
- Community roadmaps that redirect maintenance priorities
- Public forks presented as official Obscur, or third-party installers

Local experiments for your own learning are fine under [`LICENSE`](./LICENSE). Do not redistribute or rebrand them.

## If you open a pull request anyway

Unsolicited PRs may be closed without merge. If the maintainer chooses to use an idea or patch:

- You still grant the copyright holders a perpetual, worldwide, royalty-free license to use, modify, and redistribute that material as part of Obscur
- Credit is at the maintainer’s discretion (e.g. changelog / issue mention)
